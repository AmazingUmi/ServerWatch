## 范围与限制

NVIDIA 和 AMD 的解析、缺失字段、超时及错误路径用模拟数据验证；本 VPS 不具备可用 GPU 遥测，未完成真实 GPU 硬件验收。真实驱动的可用字段、权限和查询成本需要在 GPU 服务器上检查。

最近任务属于采样统计：完整发生在两个采样点之间的短进程可能不可见；跨窗口边界的 CPU 时间按采样间隔比例估计，峰值 RSS 可能来自边界前一个采样点。首次看到一个进程时不会将其此前整个生命周期的 CPU 时间算入窗口。

macOS Python 3.15 上同样通过 74 项测试和打包检查。GitHub Actions 中已配置 Linux Python 3.10／3.13 检查；云端运行结果见 [Actions](https://github.com/AmazingUmi/ServerWatch/actions)，与本文记录的实机验证分开。
